# ARA CMS V20.9.14 — Messages Detail

- Messages list rows are clickable.
- Clicking a message opens a modal with the full message content.
- Long messages are scrollable inside the detail panel.
- Unread messages are automatically marked as read when opened.
- Added `Balas via Email` action using the sender email.
- Added keyboard support: Enter/Space to open, Escape to close.
- Fixed Messages redirect flow so mark-read happens before HTML output.
- Responsive detail modal for mobile.
