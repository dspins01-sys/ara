# Ara CMS V20.9.1 — Mobile Builder UX

## Fokus
Memperbaiki UI Visual Builder pada layar mobile tanpa mengubah layout responsive website desktop/tablet.

## Perubahan
- Toolbar Visual Builder mobile dibuat compact dan 3-row.
- Device switcher tetap mudah diakses.
- Aksi utama `+ Block` dan `Menu` tetap terlihat.
- Aksi sekunder `Header`, `Slider`, `Template`, `Site Settings`, dan `Lihat Situs` dipindahkan ke menu `More` pada mobile.
- Menu More menutup setelah memilih aksi atau klik di luar.
- Canvas mobile tetap terpisah dari Builder chrome.
- Padding/top offsets Builder disesuaikan agar header, block toolbar, dan canvas tidak tertutup toolbar.
- Desktop behavior dipertahankan.
